# Intelligent Predictive Maintenance - Machine Failure Risk Management

A machine learning project focused on predicting machine failure risk and supporting proactive maintenance decisions. The repository includes a Jupyter notebook for exploratory data analysis, model training, evaluation, and comparison of predictive maintenance strategies.

## Project Highlights

- Predictive maintenance analysis for industrial machine health monitoring
- Comparison of multiple machine learning models for failure risk prediction
- Feature engineering and model evaluation workflow
- Experiment results and performance comparison summaries
- Technical report documenting the project approach and findings

## Repository Contents

- `Predictive_Maintenance.ipynb` — main notebook containing the end-to-end analysis and model implementation
- `experiment_results.csv` — output of experimental runs and model evaluation metrics
- `model_comparison.csv` — comparison summary across trained models
- `Final_Technical_Report.pdf` — project technical report

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Pinnamaneni-Annapurna25/Intelligent-Predictive-Maintenance-Machine-Failure-Risk-Management.git
   cd Intelligent-Predictive-Maintenance-Machine-Failure-Risk-Management
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate   # On macOS/Linux
   # venv\Scripts\activate  # On Windows
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Open the notebook:
   ```bash
   jupyter notebook Predictive_Maintenance.ipynb
   ```

## Usage

Run the notebook cells in order to:
- load and preprocess the dataset
- perform exploratory analysis
- train classification models
- evaluate predictive performance
- compare model results
- review the final conclusions and recommendations

## Project Goal

The goal of this project is to reduce unexpected machine downtime by identifying failure-prone equipment early using data-driven analytics and predictive modeling.
